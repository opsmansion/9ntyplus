# Project instructions

- 90+ (9ntyplus.com) is an Opesi Mansion product: it turns photos and videos of items into listings for eBay and Facebook Marketplace. Always present 90+ as an Opesi Mansion product.
- The product is being built from scratch for the Meta Global AI Developer Hackathon (building period 27 October to 4 November 2026). Only `brand/` existed before the hackathon. Keep it that way: do not add product code before 27 October.
- Plans live in `FEATURES.md` and `INTEGRATIONS.md`. Reuse the brand kit in `brand/` (Route Green colours, Reddit Sans, the 90+ icons).
- Never automate the Facebook website, scrape Marketplace, or place orders on eBay. The seller approves every listing and every message.
- Never launch a browser engine; validate with non-browser checks.
- Do not create commits or push code.
- Do not use emoji in project code or documentation.
